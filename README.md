# Student Performance Analysis

## About This Project
This is my first Data Science project, developed as part of my BS Data Science learning journey.

The project analyzes student academic performance using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Tasks
- Created a student dataset
- Checked missing values and duplicates
- Calculated average marks
- Identified the highest-performing student
- Performed statistical analysis
- Created data visualization charts
- Analyzed subject-wise performance

## Key Findings
- Total students analyzed: 5
- Best-performing student: Sara
- Lowest-performing student: Usman
- Highest-performing subject: Science
- Lowest-performing subject: Math
- Overall class average: 77.67

## Learning Outcome
Through this project, I practiced Python programming, Pandas data analysis, basic statistics, and data visualization.
